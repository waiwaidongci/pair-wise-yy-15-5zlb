# hxyfront-62014 赛鸽训放 · 离线航迹可信度复测台

面向赛鸽棚的**离线**航迹可信度复测工具（React + Vite + TypeScript，纯前端、数据仅存本机 localStorage）。

## 核心规则

- **唯一赛程**：每羽按「足环号 + 放飞时刻 + 放飞地点」形成唯一赛程，重复建立被拒绝。
- **多段鸽钟报时**：逐段录入钟面本地时刻与累计航距；钟面经「放飞地时区（固定 UTC 偏移）+ 鸽钟校准偏差」换算为标准时。
- **矛盾点三规则**：
  1. 报时时刻严格递增（不得早于放飞、不得倒挂、不得无法解析）；
  2. 分段速度不得超过设定限速（米/分）；
  3. 累计航距严格递增，且不超过司放全程 + 容差（超程）。
- **连续可信段**：首个矛盾点之后全部中断，不参与排行；仅连续可信到家（或争议经双高复核采信）的赛程进入成绩排行。
- **争议队列 / 未归巢**：争议冻结段不进排行、不计未归巢；双低驳回计未归巢，双中补测两者均暂不计，在飞赛程单独提醒。
- **双人复核解冻**：两名固定复核人各交置信档（高/中/低）与原因；同档一致才解冻
  （双高=采信进排行，双低=驳回计未归巢，双中=补测暂挂）；同一人对同一矛盾指纹重复提请沿用首条，不可覆盖。
- **失效重算 + 旧版只读**：放飞地时区、鸽钟校准、足环档案、限速/容差等判定参数一发布，
  先把旧版完整档案冻结为只读快照（版本号 +1），排行、风险与配对提示同步重算；
  报时/参数变化导致矛盾点指纹改变时，针对旧指纹的复核自动标记失效，可对新问题重新提请。
- **刷新一致**：赛程、争议队列、时间轴、排行、配对均由同一份本地档案实时派生，刷新后一致。

## 页面

鸽棚总览 · 赛程复测台 · 成绩排行 · 争议复核 · 航迹时间轴 · 判定参数档案 · 版本存档（旧版只读回看）

## 本地运行

```bash
npm install
npm run dev      # http://localhost:62014
npm run build
```

## 代码结构

- `src/domain/types.ts` — 领域模型
- `src/domain/model.ts` — 时间换算、逐段可信度分析、双人复核解冻、排行/未归巢/配对/时间轴派生
- `src/domain/seed.ts` — 演示档案（含可信、超速双高采信、倒挂冻结、在飞四类赛程）
- `src/store/` — localStorage 持久化、版本快照、派生数据 hook
- `src/ui/` — 七个页面与共享组件
